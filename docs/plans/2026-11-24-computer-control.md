# 电脑操控

- 日期：2026-11-24

## 为什么

Bot 可以操控这台电脑的主屏幕和私有桌面。Windows x64 独立应用由 Electron 主进程持有驱动和容器运行时连接。DSH 插件通过公开的工具、审批和附件接口参与执行。

## 已定的行为

- 会话的「电脑」页显示当前工作位置和桌面预览。工作位置选项为「自动」「私有桌面」「这台电脑」「关闭」。「自动」和「私有桌面」选择私有桌面，「这台电脑」选择本地桌面，「关闭」撤销授权并清空预览。私有桌面未准备好时，选择「自动」或「私有桌面」会打开「电脑与浏览器」设置。首次安装在设置向导中依次启动运行环境、准备镜像并创建桌面。向导收到首帧后展示画面，已创建但停止的桌面可以再次启动。从会话进入设置时，桌面启动后可点击「打开私有桌面」，返回原会话并授权同一位 Bot。获得授权后在主窗口内加载首帧。电脑页有独立的预览宽度，聊天区空间不足时在主窗口内展开。桌面目标标识为 `local-desktop` 与 `private-desktop`。选择「这台电脑」后由应用原生对话框确认主屏幕访问和前台输入，允许后直接显示画面。群聊需要明确选择一位当前成员作为操作者，群聊成员应知悉截图可进入会话记录并对成员可见。
- 每个 Bot 回合首次调用电脑工具时使用 DSH 的单次审批。模型需要支持图片输入。截图作为当前回合的工具结果和图片附件处理。这台电脑和私有桌面均提供截图、单击、输入文本、单键和滚动。坐标使用最近一张截图的原始像素。
- 本地桌面和每个私有桌面实例同一时刻各允许一个操作者。私有桌面预览可以刷新画面、接管输入和交还控制权。接管会取消 Bot 当前的电脑租约，等待驱动释放后才开放人工输入。被接管的 Bot 回合不能继续操控。选择目标和持有操控权各自有独立的有效期。
- 回合结束、任务停止、目标更换、离开会话、退出 Bot 模式、隐藏应用窗口和 Host 停止会按作用范围撤销授权或释放租约。关闭电脑面板会释放人工租约。重启应用后需要重新选择和批准。
- 私有桌面与本地桌面隔离，新安装使用 WSL 2 上的 rootless Podman。已有 Docker 镜像记录的安装沿用 Docker Desktop。应用校验镜像 ID、容器身份、命名卷及隔离配置。专用 Podman 虚拟机重启后若缺少资源控制器，可在向导中重新启动运行环境，应用会尝试恢复控制器并再次验证。容器以普通用户运行，限制内存、CPU 和进程数，只使用容器内的网络回环接口，开放给 Windows 的容器端口为零。主窗口使用应用 IPC 取得画面和转发输入。
- 应用退出时停止这一应用实例启动的已验证桌面容器。重新启动及用户确认的重建保留工作区和 Chromium 配置的两个命名卷。在「设置 → 电脑与浏览器」安装和启动桌面运行环境、准备镜像、检查当前隔离模式下的桌面启动并查看截图（按 Bot 隔离时先选择 Bot）、查看运行与停止的实例、预览运行中的实例、启动、重启和停止指定实例或停止全部运行实例、调整空闲停止时间和切换隔离模式。删除指定实例需经用户确认，只移除其容器，保留工作区和 Chromium 配置。切换模式时结束私有桌面的授权及操控，并保留两个模式各自的数据。

- 在桌面应用的会话侧栏点击「浏览器」会直接显示当前浏览器标签。没有标签时打开空白页和地址栏。已准备好的私有桌面可在设置中直接打开管理界面。

## 首版范围与限制

- 这台电脑通过主屏幕驱动采集画面和发送前台输入。点击绑定最近一次捕获，每次点击后需要重新查看画面。滚动范围受最近一张截图的尺寸限制。主屏幕授权可能包含用户当前打开的应用。
- 私有桌面用于离线操作，Chromium 可访问容器内的测试应用。DSH 的现有 Shell 与文件工具仍在原 Host 及其沙盒运行。单独的 DSH Desktop、DSH Web、移动端和其他桌面平台不开放这些电脑工具。
- 网络隔离应用在容器运行时。镜像准备可能下载基础镜像与 Debian 软件包。默认共享私有桌面。按 Bot 隔离时，每个 Bot 有自己的桌面、工作区和浏览器配置，同一 Bot 的对话沿用对应的实例。可设置同时运行的实例上限，范围为 1–8，默认为 2。降低上限后，已运行的桌面可以继续使用，低于上限后才能再启动实例。
